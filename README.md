# Selenium Automation Testing Framework

A scalable automation testing framework built using Selenium WebDriver, C#, NUnit, and Page Object Model (POM).

---

## 📌 Project Overview

This project is developed for automated web application testing.  
The framework follows the Page Object Model (POM) design pattern to improve code reusability, readability, and maintainability.

---

## 🚀 Technologies Used

- Selenium WebDriver
- C#
- NUnit
- Page Object Model (POM)
- Visual Studio

---

## ✨ Features

- Automated web testing
- Reusable Page Classes
- Step Definitions implementation
- NUnit test execution
- Clean and scalable framework structure
- Easy maintenance and readability

---

## ▶️ How to Run

1. Clone the repository
2. Open the solution file in Visual Studio
3. Restore NuGet packages
4. Build the project
5. Run tests using NUnit Test Explorer
